.Чтобы изменить настройки:
. {blank}
+
[subs="specialchars,attributes,quotes"]
Отредактируйте параметр `"NLog":` в конфигурационном файле Сервера приложений, {config-fs}.
+
Журнал формируется, если в конфигурационном файле Сервера приложений ({of-fs}), внутри секции `NLog`, указаны уровни журналирования:
+
.Фрагмент конфигурационного файла {of-fs}:
[source,json]
----
{
  "NLog": {
    "throwConfigExceptions": true,
    "extensions": [
      { "assembly": "NLog.Extensions.Logging" },
      { "assembly": "NLog.Web.AspNetCore" }
    ],
    "variables": {
      "fileLogLevel": "${environment:DV_FILE_LOG_LEVEL:default=Error}",
      "consoleLogLevel": "${environment:DV_CONSOLE_LOG_LEVEL:default=Info}",
      "enableFileLogging": "${environment:DV_ENABLE_FILE_LOGGING:default=false}",
      "enableConsoleLogging": "${environment:DV_ENABLE_CONSOLE_LOGGING:default=true}",
      "jsonFileLayout": {
        "type": "JsonLayout",
        "includeAllProperties": true,
        "attributes": [
          {
            "name": "timestamp",
            "layout": "${date:format=yyyy-MM-dd HH\\:mm\\:ss.fff}"
          },
          {
            "name": "level",
            "layout": "${level:upperCase=true}"
          },
          {
            "name": "module",
            "layout": "${logger}"
          },
          {
            "name": "message",
            "layout": "${message:withexception=true}"
          }
        ]
      }
    },
    "targets": {
      "async": true,
      "logConsole": {
        "type": "Console",
        "layout": {
          "type": "JsonLayout",
          "includeAllProperties": true,
          "indentJson": true,
          "attributes": [
            {
              "name": "timestamp",
              "layout": "${date:format=yyyy-MM-dd HH\\:mm\\:ss.fff}"
            },
            {
              "name": "level",
              "layout": "${level:upperCase=true}"
            },
            {
              "name": "module",
              "layout": "${logger}"
            },
            {
              "name": "message",
              "layout": "${message:withexception=true}",
              "encode": false
            }
          ]
        }
      },
    },
    "rules": [
      {
        "logger": "Microsoft.*",
        "maxlevel": "Warn",
        "final": true
      },
      {
        "logger": "DatabaseManager.Logger.*",
        "minLevel": "Info",
        "writeTo": "logDatabaseManagerFile",
        "final": true
      },
      {
        "logger": "*",
        "minlevel": "${when:when='${var:enableFileLogging}' == 'true':inner=${var:fileLogLevel}:else=Off}",
        "writeTo": "logAppServerFile"
      },
      {
        "logger": "*",
        "minlevel": "${when:when='${var:enableConsoleLogging}' == 'true':inner=${var:consoleLogLevel}:else=Off}",
        "writeTo": "logConsole"
      }
    ]
  },
}
----
<.> Путь к файлу журнала настраивается в параметре `\{gdc:baseLogFolder}`. По умолчанию используется каталог `/var/log/docsvision/fileservice` в Linux и `C:\ProgramData\docsvision\fileService\fileservice.log` в Windows.
<.> Уровень журналирования, по умолчанию используется `Warn`.
